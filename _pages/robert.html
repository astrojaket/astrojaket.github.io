ROBERT: retrievals that are easier to compare.

ROBERT is a pure-Python framework for atmospheric retrieval intercomparison. It is being developed to reveal where retrieval models agree, where they differ and which assumptions drive the conclusions we draw from exoplanet spectra.

View ROBERT on GitHub
Why ROBERT?

Transparent intercomparison

Atmospheric retrieval codes can differ in their radiative transfer, chemistry, cloud treatment, priors and numerical choices. ROBERT provides a shared framework for testing those choices and tracing their effect on an inferred atmosphere.

Built for research

Pure Python, modular by design

The project prioritises readable components, reproducible experiments and clear model comparisons. This page will grow alongside the codebase with scientific documentation, examples and results.
